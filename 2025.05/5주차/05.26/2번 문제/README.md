# 📝 알고리즘 문제 풀이 - 2025-05-26

## 문제 📖

- **문제 링크:** [백준 - 수 찾기](https://www.acmicpc.net/problem/1920)

- **문제 유형:** `자료 구조`, `정렬`, `이분 탐색`,`해시를 사용한 집합과 맵`, `집합과 맵`

- **난이도:** 실버 4

- **풀이 시간:** ⏳ 10분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. map을 선언하고 A 배열을 순회하면서 map에 없을 경우 추가를 해준다.
2. K배열을 순회하면서 map에 해당 숫자가 있을 경우 1을 추가 없을 경우 0을 추가한다.
3. 정답을 한 줄로 출력한다.
