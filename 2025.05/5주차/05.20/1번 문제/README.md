# 📝 알고리즘 문제 풀이 - 2025-05-20

## 문제 📖

- **문제 링크:** [백준 - 팩토리얼 0의 개수](https://www.acmicpc.net/problem/1676)

- **문제 유형:** `수학`

- **난이도:** 실버 5

- **풀이 시간:** ⏳ 30분 - 실제 걸렸던 시간

## ✍ 접근 방식

뒤에 숫자가 0이 나오는 경우의 수는 5가 필요하다.
N의 숫자에서 5의 배수가 몇 번 나오는지 확인하고 순회를 돌면서 5의 배수일 경우 count를 + 1 해주고 반환한다.
