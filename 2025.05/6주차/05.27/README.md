# 📝 알고리즘 문제 풀이 - 2025-05-27

## 문제 📖

- **문제 링크:** [프로그래머스 - 모음사전](https://school.programmers.co.kr/learn/courses/30/lessons/84512)

- **문제 유형:** `재귀`

- **난이도:** Level 2

- **풀이 시간:** ⏳ 50분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 모음을 정의해준다.
2. 솔루션 함수를 실행할 때마다 몇 번 실행되었는지 알기 위해서 idx를 + 1 해준다.
3. i 값이 4이상 이면 재귀를 종료한다.
4. for문을 반복하면서 현재 answer에 들어가야 하는 값을 넣어주고 정답이 맞는지 비교한다.
5. 정답이 맞을 경우 해당 idx를 출력하고 아닐 경우 solution 함수를 실행하며 i의 + 1값을 인자로 넘겨주어 재귀를 실행한다.
