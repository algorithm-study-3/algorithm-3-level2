# 📝 알고리즘 문제 풀이 - 2025-06-02

## 문제 📖

- **문제 링크:** [백준 - 2×n 타일링](https://www.acmicpc.net/problem/11726)

- **문제 유형:** `다이나믹 프로그래밍`

- **난이도:** Silver 3

- **풀이 시간:** ⏳ 10분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 점화식은 현재 값은 1번째 전 값 + 2번째 전 값이여서 기본적으로 2x1, 2x2의 값을 미리 정답 배열에 초기화 및 선언한다.
2. 2x3의 경우부터 반복문을 돌면서 정답 배열에 값을 넣어준다.
3. 넣어주는 과정에서 10007을 나눈 나머지 값을 넣는다.
4. 정답 배열에 접답을 찾아서 출력한다.
