# 📝 알고리즘 문제 풀이 - 2025-06-02

## 문제 📖

- **문제 링크:** [백준 - 비밀번호 찾기](https://www.acmicpc.net/problem/17219)

- **문제 유형:** `자료 구조`, `해시를 사용한 집합과 맵`, `집합과 맵`

- **난이도:** Silver 4

- **풀이 시간:** ⏳ 10분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. map을 초기화 및 선언을 한다.
2. map에 사이트 주소와 비밀번호를 저장한다.
3. 찾고자하는 사이트 주소의 비밀번호를 찾으면서 정답 배열에 추가한다.
4. 정답을 한 줄씩 출력한다.
