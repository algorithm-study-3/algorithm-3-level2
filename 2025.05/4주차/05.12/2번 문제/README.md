# 📝 알고리즘 문제 풀이 - 2025-05-12

## 문제 📖

- **문제 링크:** [백준 - 체스판 다시 칠하기](https://www.acmicpc.net/problem/1018)

- **문제 유형:** `브루트포스`

- **난이도:** 실버 4

- **풀이 시간:** ⏳ 하루 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 흰색으로 시작하는 체스판과 검은색으로 시작하는 체스판을 각각 비교군으로 만든다. (chess_w,chess_b)
2. 문제에서 주어진 체스판의 가로와 세로 -7 만큼 돌면서 큰 체스판 (chessboard)에 비교군 체스판을 한 개씩 덧대어 비교해보는 한다.
3. 비교할 때 현재 좌표를 함수(checkChessboard)에 넘겨준다.
4. chess_w,chess_b로 현재 체스판 위치에서 다른 점을 찾고 다르다면 + 1을 해준다.
5. 두 가지 중에 최솟값을 반환한다.

비교군을 생각하지 못 해서 많이 애 먹었다....
브루트포스 알고리즘이고 구현만 하면 되는데 비교군을 생각하지 못 했다..
앞으로 더 많이 푸는 방법밖에 없을 것 같다.
