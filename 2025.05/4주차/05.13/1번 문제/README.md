# 📝 알고리즘 문제 풀이 - 2025-05-13

## 문제 📖

- **문제 링크:** [백준 - FizzBuzz](https://www.acmicpc.net/problem/28702)

- **문제 유형:** `수학`

- **난이도:** 브론즈 1

- **풀이 시간:** ⏳ 10분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. FizzBuz 함수를 만든다.
2. 마지막 숫자를 초기화한다.
3. filterNaN에서 마지막에 들어온 값에 숫자를 계산한다.
4. 함수에 마지막 숫자 + 1을 한 값을 넘겨주고 정답을 반환한다.
