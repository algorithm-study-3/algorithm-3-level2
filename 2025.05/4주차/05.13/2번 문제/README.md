# 📝 알고리즘 문제 풀이 - 2025-05-13

## 문제 📖

- **문제 링크:** [백준 - 듣보잡](https://www.acmicpc.net/problem/1764)

- **문제 유형:** `해시를 사용한 집합과 맵`

- **난이도:** 실버 4

- **풀이 시간:** ⏳ 20분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 듣지 못한 사람들, 보지 못한 사람들을 만들고 듣도 보도 못한 사람들을 `new Map()`으로 초기화 해준다.
2. 듣지 못한 사람들, 보지 못한 사람들을 반복문으로 순회하면서 new Map에 넣어준다. 기존 데이터가 있을 경우 + 1, 없을 경우 0으로 초기화한다.
3. new Map()을 배열로 변환 후 map을 돌면서 데이터가 1인 사람들의 이름을 반환하고 0일 경우 빈 문자열을 반환한다.
4. filter를 통해서 빈 문자열을 제거하고 이름을 오름차순으로 정렬한다.
5. newArr의 길이, newArr를 \n 기준으로 출력한다.
