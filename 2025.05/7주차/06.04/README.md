# 📝 알고리즘 문제 풀이 - 2025-06-04

## 문제 📖

- **문제 링크:** [백준 - 뒤집기](https://www.acmicpc.net/problem/1439)

- **문제 유형:** `문자열`,`그리디 알고리즘`

- **난이도:** Silver 5

- **풀이 시간:** ⏳ 30분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 같은 문자열 그룹을 찾는다.
2. 첫번째 문자열을 map에 1로 하나를 넣어준다.
3. 문자열을 순회하면서 before와 현재 문자가 다를 경우 map을 확인한다.
   map에 있을 경우 + 1 없을 경우는 1로 초기화한다.
4. before를 x로 바꿔준다.
5. map에 size가 1이상일 경우 map에 객체 value 중에 최소값을 1일 경우 0을 반환한다.
