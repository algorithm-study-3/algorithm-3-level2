## 📌 문제 탐색하기

문제 번호 : 11650

문제 유형: 정렬

난이도: 중간

풀이 시간: 20분

시간 복잡도 : O(nlogn)

✍ 접근 방식

- 처음엔 버블정렬을 직접 구현하고, sort 함수를 만들어서 문제를 해결했다. -> 결과: 시간초과,,
- 퀵정렬 기반? 으로 만들어진 js에서 제공하는 sort를 이용하여 문제를 풀었다.

```js
const result = array.sort((a, b) => {
  if (a[0] < b[0]) {
    return a[0] - b[0];
  } else {
    if (a[1] < b[1]) {
      return a[1] - b[1];
    }
  }
});
```

- 조건을 만족하지 않으면 return이 undefined가 될 수 있음
- 즉, a[0] >= b[0]이고 a[1] >= b[1]이면 아무 값도 반환하지 않음 → 이 경우 브라우저마다 정렬이 예측 불가능할 수 있음

```js
const result = array.sort((a, b) => {
  if (a[0] !== b[0]) {
    return a[0] - b[0];
  } else {
    return a[1] - b[1];
  }
});
```

- a[0] 기준으로 정렬하고, 같으면 a[1] 기준으로 정렬
- 항상 숫자를 반환하므로 sort 함수가 올바르게 동작
