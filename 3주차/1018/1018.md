## 📌 문제 탐색하기

문제 번호 : 1018

문제 유형: 브루트포스

난이도: 하..

풀이 시간: 50분

시간 복잡도 : O(n)

✍ 접근 방식
다 해보기

1. 처음이 W로 시작하는 경우 -> B -> W 순서로 왔다 갔다해야함.
2. 그다음 행은 B로 시작해야한다.
3. 처음이 B로 시작하는 경우 -> W

이 2가지 경우를 비교해서 더 적은 경우의 수를 출력한다.

답지)

1. white로 시작하는 경우 -> 함수 제작 (인자로 시작 위치 받기)
2. black으로 시작하는 경우 -> 함수 제작 (인자로 시작 위치 받기)
3. 시작 인덱스를 찾기

   1. 이중 for문을 이용하여
   2. ✅ i: 행(row)의 시작 위치
      전체 행(row)이 N이라면, 8칸짜리 체스판을 시작할 수 있는 행의 위치는 0 ~ N-8까지
      ex) row = 10이라면 가능한 i 값은:
      i = 0, 1, 2 → (3개, 10-8+1 = 3개)

   3. ✅ j: 열(col)의 시작 위치
      마찬가지로 열도 8칸이 필요하므로 시작할 수 있는 열은 0 ~ M-8
