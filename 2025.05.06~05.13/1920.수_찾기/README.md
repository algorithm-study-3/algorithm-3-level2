# 📝 알고리즘 문제 풀이 - 2025-05-11

## 문제 📖

- **문제 링크:** [백준 - 1920번](https://www.acmicpc.net/problem/1920)

- **문제 유형:** 구현

- **난이도:** 실버4

- **풀이 시간:** ⏳12분

## ✍ 접근 방식

- 존재하는지 알아야 하는 숫자들의 배열에 대해 key값은 숫자, value값은 0인 객체를 만들고 이 객체로 출몰 횟수를 카운트하려 했다.
- 존재하는지 알아야 하는 숫자들의 배열에 대해 key값은 숫자, value값은 0인 객체를 만든다.
- 비교해야 하는 배열을 돌면서 해당 숫자가 있다면 value을 1로 바꾼다.
- 존재하는지 알아야 하는 숫자들의 배열을 순서대로 돌면서 value값을 answer배열에 넣는다.
- answer배열을 join해서 정답으로 출력한다.
