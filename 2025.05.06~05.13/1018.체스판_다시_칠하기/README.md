# 📝 알고리즘 문제 풀이 - 2025-05-11

## 문제 📖

- **문제 링크:** [백준 - 1018번](https://www.acmicpc.net/problem/1018)

- **문제 유형:** 구현

- **난이도:** 실버4

- **풀이 시간:** ⏳57분

## ✍ 접근 방식

- 8*8*43\*43 이 최대이기 때문에 그냥 구현으로 풀어도 된다고 판단했다.
- 8\*8로 잘라서 해당 배열들을 맨 왼쪽 위칸이 흰색, 맨 왼쪽 위칸이 검은색인 두가지 경우로 생각한다.
  - 흰색인 경우 짝수번째줄 짝수는 W 홀수는 B, 홀수번째줄 짝수는 B 홀수는 W 라는 규칙을 가진다. 이 규칙에서 벗어나면 count + 1해준다.
  - 검은색인 경우는 반대로 생각한다.
- count해준 것들 중 가장 작은 수를 정답으로 출력한다.
