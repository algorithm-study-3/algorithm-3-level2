### 📝 알고리즘 문제 풀이

### 문제 📖

문제 링크: 백준 - [1로 만들기](https://www.acmicpc.net/problem/1463)

문제 유형: DP

난이도: 실버3

풀이 시간: 스스로 못 품

## ✅ 문제 요약

정수 n이 주어졌을 때, 다음 3가지 연산 중 하나를 반복해서 수행해서 1로 만들려고 함.

1. 1을 뺀다 (n → n - 1)

2. 2로 나누어진다면, 2로 나눈다 (n → n // 2)

3. 3으로 나누어진다면, 3으로 나눈다 (n → n // 3)

- 목표: 가능한 연산 중 어떤 걸 골라야, 가장 적은 횟수로 1을 만들 수 있을까?

## 🧠 해결 아이디어 (DP 사고 흐름)

- 작은 문제부터 큰 문제로 쌓아간다

  - dp[i]: 숫자 i를 1로 만들기까지 필요한 최소 연산 횟수

- 기본값 설정
  - dp[1] = 0 (이미 1이니까 연산 0번)

## 점화식 구성

숫자 i를 1로 만들기 위해 올 수 있는 방법:

- i - 1에서 +1번 연산

- i // 2에서 +1번 연산 (단, i가 2로 나누어질 때)

- i // 3에서 +1번 연산 (단, i가 3으로 나누어질 때)

그래서,

```python
dp[i] = min(dp[i-1] + 1, dp[i//2] + 1 if i % 2 == 0, dp[i//3] + 1 if i % 3 == 0)
```
