# 📝 알고리즘 문제 풀이 - 2025-05-22

## 문제 📖

- **문제 링크:** [백준 - 1463번](https://www.acmicpc.net/problem/1463)

- **문제 유형:** 다이나믹 프로그래밍

- **난이도:** 실버3

- **풀이 시간:** ⏳20분

## ✍ 접근 방식

- 4의 최소값은 -1을 빼고, 뺀 값3은 3으로 나누어 떨어지기에 2이다. 3은 -1과 3의 최소값을 더하면 4의 최소값이 된다. 이처럼 작은 문제들의 답으로 큰문제의 답을 구할 수 있어서 dp로 접근했다.
- 1로 만드는 방법의 최소값을 요소의 값으로 두는 배열을 생성한다.
- -1인 경우를 기본으로 두고, 나누어진다면 각각을 dp[i]로 둔다. 이중 최소값을 해당 인덱스의 요소로 할당한다.
