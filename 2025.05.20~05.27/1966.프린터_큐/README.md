# 📝 알고리즘 문제 풀이 - 2025-05-20

## 문제 📖

- **문제 링크:** [백준 - 1966번](https://www.acmicpc.net/problem/1966)

- **문제 유형:** 구현, 자료 구조, 시뮬레이션, 큐

- **난이도:** 실버4

- **풀이 시간:** ⏳1시간 30분

## ✍ 접근 방식

- 100까지 밖에 없어서 시간복잡도가 작다 판단하여 구현으로 풀었다.
- 중요도를 담은 배열 arr와함께 중요도 index를 담은 index라는 배열을 만든다.
- 중요도배열과 index배열의 가장 첫번째 값을 뽑는다.
- 이 값(중요도 배열의 첫번째 값)보다 중요도가 더 큰게 있다면 뒤로 다시 넣는다.
- 이 값(중요도 배열의 첫번째 값)보다 중요도가 더 큰게 없다면 문서를 인쇄 수인 count를 + 1해주고 현재 index와 찾고자하는 문서의 인덱스인 m을 비교한다. 같다면 count를 정답 배열에 추가
