# 📝 알고리즘 문제 풀이 - 2025-05-20

## 문제 📖

- **문제 링크:** [백준 - 2579번](https://www.acmicpc.net/problem/2579)

- **문제 유형:** 다이나믹 프로그래밍

- **난이도:** 실버3

- **풀이 시간:** ⏳1시간 30분

## ✍ 접근 방식

- 아래와 같이 계단을 올라가는 방법을 적다보면 작은 문제로 큰 문제를 해결하는 것을 볼 수 있다.
- 그래서 특정 계단의 최대값은 이제까지의 최대값을 토대로 만들어지는 것이라 dp를 떠올림
- 연속 세칸을 건널 수 없기 때문에 "이전을 밟지않으면서 현재계단", "이전을 밟고 현재계단" 두가지를 모두 고려해야 해서 dp배열을 이중배열로 관리함

```
/**
 *
// 10
    // 20
        // 25
            // 20 => 75
    // 15
        // 25
            // 20 => 70
        // 10
            // 20 => 55

// 20
    // 15
        // 10
            // 20 => 65
    // 25
        // 10
            // 20 => 75
 */
```
