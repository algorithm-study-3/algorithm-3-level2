# 📝 알고리즘 문제 풀이 - 2025-05-13

## 문제 📖

- **문제 링크:** [백준 - 1764번](https://www.acmicpc.net/problem/1764)

- **문제 유형:** 자료구조 문자열 정렬 해시맵

- **난이도:** 실버4

- **풀이 시간:** ⏳20분

## ✍ 접근 방식

- 듣도못한 사람을 체크하는 obj를 만든다.
- 보도못한 사람이 있다면 해당 속성의 value 를 +1 해준다.
- 0이 아닌 value값을 가지는 사람 이름의 길이와 사람들의 이름을 사전순으로 정렬한 값을 출력한다.
